A safety and hardening release. Upgrading is recommended if you stop processes from lhwatch on hosts that run Docker or Podman.

## Safer stopping

- **Container port forwarders are never stopped.** `docker-proxy`, `rootlesskit`, `rootlessport`, `slirp4netns`, `pasta`, `gvproxy`, and Docker Desktop's backend are refused whoever owns them. This also covers rootless Podman.
- **An uninspectable Docker daemon you own blocks stopping.** If a Docker socket owned by you exists but cannot be inspected (no `docker` CLI on the host, or `DOCKER_HOST` pointing at another machine), ordinary processes are not stoppable, because a rootless daemon's port proxies run as you.
- **Confirmations use the latest observation.** Pressing `y` refuses if the endpoint disappeared or became ineligible after the confirmation opened.

## Fixes

- A tunnel whose close fails stays listed, so `O` can retry it.
- Opening a tunnel with no free local port reports that clearly.
- Search also matches endpoint purposes and stop reasons.
- A relative `XDG_CONFIG_HOME` is ignored, as the XDG spec requires.

## Release artifacts

- Built with the latest stable Go and scanned with govulncheck using that toolchain.
- Each archive now includes `LICENSE`.
- Dependencies updated: Bubble Tea 2.1.1 and `charmbracelet/x/ansi` 0.11.9; CI uses `actions/checkout` v7 and `actions/setup-go` v7.
- Every archive and `SHA256SUMS` has a signed build-provenance attestation:

```sh
gh attestation verify lhwatch_v0.1.1_linux_amd64.tar.gz --repo joeynyc/lhwatch
```

## Install

Download the archive for your platform below, check it against `SHA256SUMS`, extract it, and put `lhwatch` on your `PATH`. Monitored hosts need Python 3.9+. Binaries are not code-signed. See the README for configuration.
