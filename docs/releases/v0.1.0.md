The first release of lhwatch: a terminal dashboard for the TCP services running on your Mac, Linux machines, and SSH hosts.

## Highlights

- **One live view of every listener** on this machine and your SSH hosts, refreshed independently per host. A disconnected host stays visibly stale instead of disappearing.
- **Services you recognize.** Rows lead with the project or app name from `.lhwatch.json`, `package.json`, project markers, or macOS app bundles, and group every endpoint of one verified process or container.
- **Container awareness.** Docker Compose project and service names, host-network ownership from real socket evidence, and protection for processes in Docker, Podman, containerd, CRI-O, Kubernetes, and LXC containers.
- **Endpoint purposes** from `.lhwatch.json` and explicit SGLang, vLLM, and Python `http.server` launch ports. Nothing is guessed from port numbers.
- **Open in a browser with `o`.** Remote services are forwarded over SSH to `127.0.0.1` on your machine.
- **Deliberate stops with `x`.** SIGTERM only, after the collector revalidates the process identity, owner, and listener on that host (pidfd on Linux).
- **Scriptable snapshots** with `--json`, and a fully simulated `--demo`.
- **Light on your hosts.** No daemon or install: an ephemeral Python 3.9+ collector over your existing SSH setup, reusing one connection per host.

## Install

Download the archive for your platform below, check it against `SHA256SUMS`, extract it, and put `lhwatch` on your `PATH`. Use `linux_arm64` for ARM64 Linux hosts such as a DGX Spark. See the README for configuration.

Monitored hosts need Python 3.9+; macOS also uses the system `lsof` and `ps`. Binaries are not code-signed.
